Project Overview

This website is developed to understand the basic concept of cloud hosting. It shows how HTML and CSS files can be uploaded to GitHub and published online using GitHub Pages.

Purpose of the Lab

The main purpose of this lab is to practice deploying a static website on a cloud platform. GitHub Pages acts as the hosting service and makes the website available through a public URL.

Technologies Used

  • HTML for website structure
  • CSS for styling and design
  • GitHub for storing project files
  • GitHub Pages for cloud hosting
