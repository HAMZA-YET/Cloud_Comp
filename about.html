About This Project

Understanding cloud deployment through a real static website project.

Project Overview

CloudSphere is a cloud computing lab project developed to demonstrate how a simple static website can be deployed online using GitHub Pages. The website includes multiple pages, navigation, styling, and responsive design.

Purpose

The purpose of this project is to understand the concept of cloud hosting. Instead of running the website only on a local computer, the files are uploaded to GitHub and served publicly through GitHub Pages.

Technologies Used

HTML5 CSS3 GitHub GitHub Pages Cloud Hosting

Learning Outcome

This project helps students understand how websites are hosted on cloud platforms, how files are managed in repositories, and how deployment works using GitHub Pages.
