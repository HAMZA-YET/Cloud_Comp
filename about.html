Cloud Computing Practical Lab

Project Overview

This website is created for a cloud computing practical lab. It demonstrates how a static website can be uploaded to GitHub and published online using GitHub Pages.

Purpose

The purpose of this project is to understand basic cloud deployment. Instead of opening the website only on a personal computer, the website is hosted online so anyone can access it through the internet.

Technologies Used
